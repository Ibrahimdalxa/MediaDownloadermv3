✦ Installation

Up and running in
4 simple steps

No technical skills needed — just follow these steps and you're done!

ℹ️

Developer Mode Required

Since this extension isn't on the Chrome Web Store yet, you'll need to enable Developer Mode once — it's completely safe and reversible.

1

Download & Extract the ZIP

Click the green "Code" button on GitHub → "Download ZIP", then extract it anywhere on your PC.

2

Open Extensions Page

Type chrome://extensions/ in your address bar and press Enter.

3

Enable Developer Mode

Toggle "Developer mode" ON in the top-right corner of the Extensions page.

4

Load Unpacked & Done!

Click "Load unpacked" → select the extracted folder → click Select Folder. That's it! 🎉
